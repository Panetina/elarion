# LORE

Root lore summary for the current Elarion direction.

## Current Direction

Elarion is a realm-based civilization server where identity, contribution,
economy, politics, war, diplomacy, and public memory reinforce each other.

The current setting keeps:

- Realms as the social unit
- Worldheart as the shared civic center
- Shrine / Offering systems as civic progression
- Economy as the official currency and service layer
- NPCs as presentation and interaction surfaces
- Portals as scheduled, ticketed travel infrastructure
- Government as a gated civic authority system
- Groups as reusable faction / delegate identity

## Folklore

Detailed stories and character chronicles live under:

- `lore/folklore/README.md`
- `lore/folklore/characters/`
- `lore/folklore/chronicles/`

Those files are the long-form lore archive.
This root file is only the compact summary and navigation anchor.

## Writing Rule

Keep lore aligned with implemented systems and current naming.
Do not let obsolete terminology drift back into the active story layer.
