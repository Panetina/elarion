# AI Handoff Archive

This directory preserves superseded handoff, plan, and TODO history. It is
indexed from `INDEX.md` for deliberate historical recovery but excluded from
normal context retrieval and Vexp indexing.

Current source, `RULES.md`, `docs/ai/CURRENT_STATUS.md`, and authoritative
system/addon documentation override archived statements.

- `CURRENT_STATUS_THROUGH_2026-07-11.md`: verbatim pre-compaction status log.
- `PLAN_THROUGH_2026-07-11.md`: verbatim pre-compaction plan log.
- `TODO_THROUGH_2026-07-11.md`: verbatim pre-compaction TODO list.
- `RULES_THROUGH_2026-07-11.md`, `AGENTS_THROUGH_2026-07-11.md`, and
  `CODEX_THROUGH_2026-07-11.md`: pre-compaction root context retained for
  historical recovery.
- `AI_SEARCH_HINTS_THROUGH_2026-07-11.md`: pre-route-catalog prose shortcuts.
