# Guilds

Admin guide for reusable public player guilds.

[Home](../README.md) | [Admin](README.md) | [Commands](commands.md)

## Status

`Implemented and locally verified`

Guilds are public player-created organizations. V1 supports one guild per
player, one leader, invites, membership management, guild chat, and admin
inspection. Secret societies, cities, guild types, and political-party style
metadata are future work.

## Config And Runtime

Config:

```text
config/elarion/addons/guilds/guilds.yml
```

Runtime:

```text
world/elarion/addon-state/guilds/guilds.json
```

Config controls the creation fee, guild ID pattern, public tag pattern, tag
length, blocked tags, and maximum display-name length.

## Player Commands

```text
/guild
/guild invite <player>
/guild accept <guild>
/guild kick <player>
/guild leave
/guild transfer <player>
/guild info [guild]
/gc <message>
```

Guild creation is only available through the configured Guild Registrar NPC
action. The Registrar owns no Guild data: Guilds validates the request and
Economy sinks the configured fee. The screen always shows the live configured
fee and wallet balance. The player enters a name, public tag, and visibility;
the stable internal Guild ID is generated by the server.

## Admin Commands

```text
/e guilds reload
/e guilds list
/e guilds inspect <guild>
/e guilds delete <guild>
/e guilds transfer <guild> <player>
```

## Public Rendering

Only the public tag renders next to a player identity:

```text
[MERC] PlayerName
Ember
```

Full display names, roles, bounded announcements, eligible online invitation
targets, and 32x32 emblems appear in the themed six-tab Guild UI. Emblems are
never rendered in chat.

## Government Integration

Government no longer uses Guilds for active founding offices. Guilds remains a
reusable social/faction system for future mechanics.
