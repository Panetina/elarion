# Shrine Fantasy UI Mockup V1

Approval-only visual artifacts for the Elarion fantasy UI skin.

No production code, theme configuration, or runtime resources use these files.

## Files

- `shrine_fantasy_mockup_520x360.png`: native logical-resolution mockup.
- `shrine_fantasy_mockup_preview_1040x720.png`: 2x nearest-neighbor preview.
- `shrine_fantasy_asset_map_1560x720.png`: numbered implementation map.

## Static And Dynamic Boundaries

Static PNG chrome:

1. Background tile.
2. Outer frame nine-slice and corner ornaments.
3. Header nine-slice and fixed crest ornament.
4. Progress track/fill endcaps.
5. Card and inset nine-slices.
6. Tab state nine-slices.
7. Requirement row and selection nine-slices.
8. Reward slot and icon-frame nine-slices.
9. Button state nine-slices.
10. Status ribbon and divider sprites.

Dynamic code-rendered content:

- Titles, subtitles, level labels, status text, and button labels.
- Progress values and fill width.
- Project icon, item icons, currency icons, reward stacks, and stack counts.
- Requirement rows, history rows, lists, scrolling, hover states, and tooltips.
- Input values, modal prompts, hitboxes, and all server-authoritative actions.

## Proposed Slice Margins

- Outer frame: 12 px.
- Header: 8 px.
- Card/inset: 6 px.
- Tabs/buttons/rows: 5 px.
- Slots: 4 px.
- Progress track: 4 px horizontal endcaps.

All values are logical pixels and remain subject to approval of this mockup.
